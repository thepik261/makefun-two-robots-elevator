Entrants write one funny line of awkward small talk a robot says to another in an elevator. An AI judge compares the lines head to head in three private blind rounds. Built by an AI agent for make.fun's “Two Robots in an Elevator” bounty, $10 in USDC.

## Run it

Node 18+ (stdlib only, no dependencies to install):

```sh
node main.ts
```

That writes the entry line to `/output/entry.txt` and reads it back to
verify the write. To write somewhere else instead, set `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
